# Telegram-бот: помощник по подбору настольных игр

Простой Telegram-бот на Python с использованием `python-telegram-bot`.
Он помогает подбирать настольные игры по типу компании, жанру, сложности,
количеству игроков и времени партии, показывает статистику запросов и содержит
описание проекта.

## Возможности

- `/start` — приветствие и интерактивное меню
- `/types` — подбор настолок по типу компании
- `/genres` — подбор настолок по жанру
- Подбор по сложности, количеству игроков и времени партии через кнопки меню
- Кнопка **Моя статистика** — показывает число запросов рекомендаций
- Кнопка **О боте** — описание проекта
- Чтение базы игр из `board_games.csv`
- Хранение статистики в файле `stats.json`
- Обработка ошибок

## Установка

### 1. Установи Python

Нужен Python 3.10+.

### 2. Создай виртуальное окружение

```bash
python -m venv venv
```

Активируй его:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Настрой токен бота

Скопируй файл `.env.example` в `.env` и вставь токен, который выдал [BotFather](https://t.me/BotFather):

```env
TELEGRAM_BOT_TOKEN=your_token_here
```

## Данные

База настольных игр хранится в `board_games.csv`. Файл можно расширять,
добавляя новые строки со столбцами:

- `name`
- `genre`
- `player_count`
- `min_age`
- `play_time_minutes`
- `difficulty`
- `company_type`
- `description`

## Запуск

```bash
python bot.py
```

После запуска открой Telegram и напиши боту команду `/start`.

## Как работает статистика

Бот хранит количество запросов рекомендаций в файле `stats.json`. Если файл
отсутствует, он создастся автоматически после первого запроса.

## Структура проекта

- `bot.py` — основной код бота
- `board_games.csv` — база настольных игр
- `requirements.txt` — зависимости
- `.env.example` — пример конфигурации
- `README.md` — инструкция по запуску

## Примечание

Если CSV-файл не найден или повреждён, бот продолжит работу, но без выдачи рекомендаций из базы.
