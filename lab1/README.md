## 1. Описание задачи

### Какую проблему решает бот
Бот помогает быстро подобрать настольную игру под конкретную ситуацию:
- по типу компании;
- по жанру;
- для соло-игры;
- для семейного вечера или большой компании.

Он упрощает выбор настолки, когда пользователю сложно самостоятельно определиться среди множества игр.

### Почему выбрали именно эту задачу
Тема настольных игр удобна для демонстрации логики рекомендаций, меню с кнопками, работы со статистикой и хранения данных в файле.  
Кроме того, это понятная и полезная бытовая задача: бот помогает сократить время на выбор игры и делает этот процесс удобнее.

## 2. Промпт для LLM

### Исходный промпт
> Напиши Telegram-бота на Python с использованием библиотеки python-telegram-bot.  
>
> Тематика бота: Помощник по подбору настольных игр.
>
> Функционал бота:
> 1. Приветствие по команде /start с выводом интерактивного меню (кнопок клавиатуры).
> 2. Вывод категорий настолок по типам компании (для двоих, для большой компании, семейные, соло) по команде /types или кнопке.
> 3. Вывод настолок по жанрам (стратегии, детективы, экономические, пати-геймы) по команде /genres или кнопке.
> 4. Кнопка "Моя статистика", которая показывает, сколько раз пользователь запрашивал рекомендации.
> 5. Кнопка "О боте" с текстовым описанием проекта.
>
> Требования к коду и структуре:
> - Бот должен быть простым, понятным.
> - Код должен быть очень хорошо прокомментирован на русском языке.
> - Использовать файл для хранения данных (JSON или SQLite)
> - Добавить обработку ошибок
>
> Создай и выведи 4 отдельных файла:
> 1. Файл bot.py — основной код бота со встроенной базой из 10-15 популярных настольных игр.
> 2. Файл requirements.txt.
> 3. Файл README.md с инструкцией по запуску.
> 4. Файл .env.example — шаблон конфигурации для токена (TELEGRAM_BOT_TOKEN).

## 3. Стек технологий

### Какие библиотеки использовались
- `python-telegram-bot` — основная библиотека для создания Telegram-бота;
- `python-dotenv` — для загрузки токена из файла `.env`;
- стандартные библиотеки Python:
  - `json`
  - `logging`
  - `random`
  - `os`
  - `pathlib`
  - `dataclasses`

### Почему выбрали именно их
- `python-telegram-bot` — удобная и популярная библиотека для Telegram Bot API;
- `python-dotenv` — помогает безопасно хранить токен отдельно от кода;
- стандартные модули Python позволяют реализовать логику бота без лишних зависимостей.
