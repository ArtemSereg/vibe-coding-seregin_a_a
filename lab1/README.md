# Telegram-бот: помощник по подбору настольных игр

Простой Telegram-бот на Python с использованием `python-telegram-bot`.
Он помогает подбирать настольные игры по типу компании и по жанру, показывает статистику запросов и содержит описание проекта.

## Возможности

- `/start` — приветствие и интерактивное меню
- `/types` — подбор настолок по типу компании
- `/genres` — подбор настолок по жанру
- Кнопка **Моя статистика** — показывает число запросов рекомендаций
- Кнопка **О боте** — описание проекта
- Хранение статистики в файле `stats.json`
- Обработка ошибок

Ниже приведён мой первый промпт с требованиями к созданию бота:

> Напиши Telegram-бота на Python с использованием библиотеки python-telegram-bot.  
>
> Тематика бота: Помощник по подбору настольных игр.
>
> Функционал бота:
> 1. Приветствие по команде /start с выводом интерактивного меню (кнопок клавиатуры).
> 2. Вывод категорий настолок по типам компании (для двоих, для большой компании, семейные, соло) по команде /types или кнопке.
> 3. Вывод настолок по жанрам (стратегии, детективы, экономические, пати-геймы) по команде /genres или кнопке.
> 4. Кнопка "Моя статистика", которая показывает, сколько раз пользователь запрашивал рекомендации.
> 5. Кнопка "О боте" с текстовым описанием проекта.
>
> Требования к коду и структуре:
> - Бот должен быть простым, понятным.
> - Код должен быть очень хорошо прокомментирован на русском языке.
> - Использовать файл для хранения данных (JSON или SQLite)
> - Добавить обработку ошибок
>
> Создай и выведи 4 отдельных файла:
> 1. Файл bot.py — основной код бота со встроенной базой из 10-15 популярных настольных игр.
> 2. Файл requirements.txt.
> 3. Файл README.md с инструкцией по запуску.
> 4. Файл .env.example — шаблон конфигурации для токена (TELEGRAM_BOT_TOKEN).
